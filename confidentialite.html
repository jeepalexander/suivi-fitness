MON CARNET DE SALLE

Règles de confidentialité

Dernière mise à jour : 9 novembre 2026

En bref : tes séances restent sur ton téléphone. Si tu actives la sauvegarde Google Drive, elles sont copiées dans ton Google Drive, dans un dossier créé par l'application. L'application n'a pas de serveur : personne d'autre que toi, pas même son auteur, n'a accès à tes données.

Qui est responsable de l'application

Mon Carnet de Salle est une application web gratuite de suivi d'entraînement en salle, publiée à l'adresse https://jeepalexander.github.io/suivi-fitness/. Pour toute question : jeanphilippealexander@gmail.com.

Les données que tu saisis

Programmes, séances, exercices, charges, répétitions, durées, réglages (thème, fond d'écran…) : tout est enregistré uniquement dans le stockage local de ton navigateur, sur ton appareil. Ces données ne sont envoyées nulle part, sauf vers ton propre Google Drive si tu actives la sauvegarde (voir ci-dessous).

Sauvegarde Google Drive (facultative)

Si tu touches « Connecter Google Drive », Google te demande l'autorisation pour une seule permission : https://www.googleapis.com/auth/drive.file. Elle permet à l'application de voir et de gérer uniquement les fichiers qu'elle a elle-même créés dans ton Drive. Elle n'a accès à aucun autre fichier de ton Drive.

Avec cette autorisation, l'application :

  • crée dans ton Drive un dossier « MON CARNET DE SALLE » ;
  • y enregistre une copie de tes données (fichier JSON) à chaque séance validée, garde les 5 copies les plus récentes et supprime les plus anciennes qu'elle a créées ;
  • relit ces copies quand tu demandes une restauration ;
  • lit le nom et l'adresse e-mail de ton compte Google (via l'API Google Drive) pour t'indiquer, dans Réglages, sur quel compte tes sauvegardes sont faites. Ces informations restent sur ton appareil.

Le jeton d'accès fourni par Google est conservé dans le stockage local de ton navigateur et sert uniquement à ces opérations, directement entre ton appareil et Google. Il expire de lui-même au bout d'une heure.

L'utilisation des informations reçues des API Google respecte le règlement de Google sur les données utilisateur des services d'API (Google API Services User Data Policy), y compris les exigences d'utilisation limitée (« Limited Use »). Les données Google ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires, ni utilisées pour entraîner des modèles d'intelligence artificielle.

Ce que l'application ne fait pas

  • Pas de compte à créer, pas de serveur de l'application, pas de base de données distante.
  • Pas de publicité, pas de mesure d'audience, pas de traceur ni de cookie publicitaire.
  • Aucune donnée n'est transmise à l'auteur de l'application ni à des tiers.

Hébergement

Les fichiers de l'application sont hébergés par GitHub Pages (GitHub, Inc.). Comme tout hébergeur, GitHub peut enregistrer des données techniques de connexion (adresse IP, navigateur) lors du téléchargement de l'application ; voir la déclaration de confidentialité de GitHub. Une fois installée, l'application fonctionne sans connexion.

Supprimer tes données ou retirer l'accès

  • Sur ton appareil : efface les données du site dans les réglages de ton navigateur, ou désinstalle l'application.
  • Dans ton Drive : supprime le dossier « MON CARNET DE SALLE ».
  • Accès Google : touche « Déconnecter » dans Réglages, et retire l'application depuis myaccount.google.com/permissions.

Modifications

Ces règles peuvent évoluer avec l'application. La date de dernière mise à jour figure en haut de la page.

Summary in English

Mon Carnet de Salle is a free gym-training log web app with no backend. All workout data is stored only in the browser's local storage on the user's device. If the user enables Google Drive backup, the app requests only the drive.file scope: it creates a "MON CARNET DE SALLE" folder in the user's own Drive, writes a JSON backup after each workout (keeping the 5 most recent), reads those backups back on request, and reads the account name and email (Drive API about) to show which account is used. Google user data never leaves the user's device except for these direct calls to Google APIs; it is not sent to the developer or any third party, not sold, not used for advertising or to train AI models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time in the app (Disconnect) or at myaccount.google.com/permissions, and delete the Drive folder. Contact: jeanphilippealexander@gmail.com.
